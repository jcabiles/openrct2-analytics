## Director rulings (Gate 2 auto-build stays valid only with these; each is the more careful reading)

- Ruling 1 (managed day and the 1 March year end; Argon A-6, Fable B-2, B-19; replaces the spec's owner question 1). A managed day is a `park_snapshot` of a registered company park (not practice) in a session the label feed does not list as `autopilot`, whose `seq` is at or below that session's last `save_written` `seq`: play after a session's last save is never kept (ADR 0024 line 20), so it never counts. A 1 March day of game year g counts toward g - 1 when the same session also has a managed day in game year g - 1; otherwise it counts toward g. Basis: roadmap line 127 defines a stop on 1 March of the next game year as "before any day of the next year is played", so no new owner decision is needed. "A managed session in Y + 1" (roadmap line 127) is read as "a managed day in Y + 1", because a session shorter than one game day has no `park_snapshot`; the spec says so. Unit cases cover: days after the last save; a session that starts on 1 March; Park 2's first session starting 1 March of game year 1; a park playing several years.
- Ruling 2 (abandoned branches; Fable B-3; replaces the spec's owner question 6). The year rule keeps reading converted Parquet, as the run's start-year ruling fixes ("Park 1's last managed year comes from its park_snapshot game dates in converted Parquet"). The spec states both effects truthfully: abandoned managed days can refuse a run and can also allow one (a try-out of the managed park into Y + 2 that is later abandoned). ADR 0049 and the AGENTS.md command entry record the second case; no kept-timeline read is added.
- Ruling 3 (probe first; Fable B-4). Not accepted as a build block. The run's standing rulings let the build proceed on stand-in tests when no quiet window opens, and make the real end-to-end run a hand check. The spec gains a step 0 in Verify-by that states the probe, its pass rule, and the rulings: a failed probe gets one fix round and one re-probe, then the autopilot and label items park.
- Ruling 4 (helper; Argon A-2, A-7, Fable B-9). The command renders the target year into the helper text from the source save's game year g (target g + 1); the helper arms on the day callback of 1 March of that year and saves 200 ticks later. Without a target year the helper keeps today's rule, so the rehearsal chain and `tests/test_rehearsal_helper.py:73` stay as they are. The helper is passed the save-file stem without `.park`; the stand-in reads the target year from the helper text.
- Ruling 5 (landing; Fable B-6, B-12, Argon A-13). The work folder's raw files are joined in order into one raw file per session, so the raw step is one link. Record files keep their own stems plus `-autopilot-<session id>`. The staged label file is checked by the label checker together with the existing deliveries before the first link; a failure means nothing landed. The landing waits a bounded time for the lock before failing. Signals are ignored from the first link to the end of the report. R9 is reworded to what is true: a label or record file may land without its session; a raw session never lands in part or without its label. Tests cover a failure between links, a taken lock and an interrupt after the landing.
- Ruling 6 (refusal order; Argon A-17, Fable B-13). Cheap checks first, then checks that guard the folders, then the game checks, then the data reads: settings and the write boundary and alias checks come before any data folder is read; the game process and live-autosave checks come before Parquet is read; `--version` sits where `rehearsal_capture.py` has it, before the load wait; refusal 2 prints plain text without the park list.
- Ruling 7 (source proof; Argon A-4, A-5, A-15, Fable B-1, B-14). Refuse when the converted Parquet or audit is missing, or when any `raw/v1/events-*.jsonl` holds a session missing from `session_start.parquet` ("run make convert DATA_SET=company first"). The newest archive copy is chosen by the time parsed from the end of its name; the proof compares the copy's modified time and size with the paired save-file record, never the name's time with `emitted_at`. The per-run pairing loop of `judge_saves` becomes one public function used by both. The source game date and `seq` are read from `save_written.parquet` by `event_id`. A renamed-park test is added.
